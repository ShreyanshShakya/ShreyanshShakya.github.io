# Brain MRI Tumor Segmentation with 3D U-Net Architectures

Brain tumor segmentation is a challenging medical-imaging problem because the model has to reason over volumetric MRI data while distinguishing relatively small tumor regions from a much larger background.

This project was designed as a comparative study rather than a search for a single complicated architecture. The main question was simple: **how much does each architectural change improve volumetric segmentation?**

## The Dataset

The project uses the **BraTS 2020** dataset, containing multi-modal MRI scans and expert tumor segmentation masks. Four MRI modalities are used as input:

- T1
- T1ce
- T2
- FLAIR

The original BraTS labels are remapped into three tumor classes plus background for training.

## Experimental Approach

I evaluated three architectures while progressively introducing architectural changes:

```text
BraTS 2020
    ↓
Preprocessing + Tumor-aware Sampling
    ↓
Baseline 3D U-Net
    ↓
EfficientNet-based 3D U-Net
    ↓
EfficientNet + Attention 3D U-Net
    ↓
Validation
```

The goal was to compare the models using the same general training pipeline and observe whether each architectural change produced a measurable improvement.

## Experiment 1: Baseline 3D U-Net

The first model established a conventional volumetric segmentation baseline using a 3D U-Net encoder-decoder with skip connections, 3D convolution blocks, normalization, ReLU activations, and transposed-convolution upsampling.

The project README reports a **best validation Dice score of 0.8057** and an IoU of **0.7349** for the baseline model.

## Experiment 2: EfficientNet-based 3D U-Net

The next experiment replaced the baseline encoder with EfficientNet-inspired MBConv blocks. The design uses depthwise-separable 3D convolutions, squeeze-and-excitation blocks, residual connections, and efficient feature extraction.

The validation Dice increased to **0.8157**, while IoU increased to **0.7427**.

This experiment showed that changing the encoder could improve the representation learned from the volumetric MRI data without abandoning the U-Net structure.

## Experiment 3: EfficientNet + Attention

The final architecture added attention mechanisms to the decoder pathway on top of the EfficientNet-based encoder.

The purpose was to make the skip connections more selective: instead of passing all encoder features equally into the decoder, attention gates help emphasize relevant tumor features and suppress irrelevant background information.

This produced the strongest result in the study:

- **Dice: 0.8256**
- **IoU: 0.7575**

Compared with the baseline, the final architecture improved Dice by **2.47 percentage points**.

## Training Pipeline

The repository documents the following training components:

- NIfTI MRI volumes loaded with NiBabel
- Four MRI modalities combined into a 4-channel input
- Per-modality Z-score normalization
- Non-zero voxel normalization
- Label remapping
- Tumor-aware patch sampling
- Data quality filtering
- Mixed-precision training with AMP
- Adam optimizer
- Dice + Cross Entropy loss
- Early stopping
- Model checkpointing
- Validation monitoring

These choices address practical issues in 3D medical imaging, especially the large memory footprint of volumetric convolutions and the imbalance between tumor and background voxels.

## Results

| Model | Validation Dice | Validation IoU |
|---|---:|---:|
| Baseline 3D U-Net | 0.8057 | 0.7349 |
| EfficientNet U-Net | 0.8157 | 0.7427 |
| EfficientNet + Attention U-Net | **0.8256** | **0.7575** |

The progression is consistent: the EfficientNet-based encoder improves over the baseline, and adding attention produces the best validation performance.

## What I Learned

### 1. Architecture should be evaluated incrementally

Changing one major component at a time makes it easier to understand where an improvement comes from.

### 2. 3D segmentation is a memory-constrained problem

Volumetric models require careful training strategies. Patch-based processing and mixed precision are practical tools for making 3D training feasible.

### 3. Tumor-aware sampling matters

When the background dominates the volume, sampling strategies that expose the model to tumor-containing regions can make training more useful.

### 4. Attention can improve feature refinement

In this experiment, adding attention to the EfficientNet-based U-Net produced the best validation Dice and IoU.

## Conclusion

The project demonstrates a straightforward progression from a **3D U-Net baseline → EfficientNet-based encoder → attention-enhanced architecture**.

The final model reached a validation Dice of **0.8256** and IoU of **0.7575** on the project evaluation setup. The most important takeaway was not simply that the final architecture performed best, but that controlled architectural comparisons made the improvement understandable.

## Future Work

Potential extensions include evaluation of individual BraTS tumor regions, stronger volumetric architectures, self-supervised pretraining, multi-modal feature fusion, and more extensive validation across different datasets.
